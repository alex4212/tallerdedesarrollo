# Sistema Web Integrado - Aldea Infantil SOS Angol


## Descripción del Proyecto
Este es un sistema web integrado desarrollado para la digitalización y optimización de la gestión operativa, de seguridad y sostenibilidad de la Aldea Infantil SOS Angol. El proyecto busca centralizar la información de los turnos rotativos, automatizar alertas de mantenimiento y dotar a la seguridad externa de una herramienta de monitoreo eficiente, transformando los procesos analógicos en un ecosistema digital robusto.


## Características Principales

El sistema está dividido en tres módulos operativos con accesos estructurados mediante autenticación por correo electrónico estándar (sin restricción de dominios institucionales) para facilitar el ingreso de usuarios internos y externos.

### 1. Módulo de Acogida (Gestión de Casas)
* Gestión de ingreso y asignación de menores a viviendas.
* Visualización en tiempo real de las educadoras responsables y control de turnos rotativos (4x4).
* Trazabilidad de la información crítica durante los traspasos de turno.

### 2. Módulo de Sostenibilidad (Mantenimiento y Finanzas)
* Sistema de notificaciones y alertas automatizadas para tareas periódicas (ej. aseo quincenal de cañones de calefacción).
* Panel de carga digital de boletas para la rendición descentralizada de presupuestos por cada casa.
* Historial de gastos e insumos.

### 3. Módulo de Protección Activa (Seguridad)
* Interfaz de solo lectura diseñada específicamente para los guardias externos.
* Panel de monitoreo que visibiliza la ocupación de las zonas sensibles del recinto.
* Optimización de rondas y vigilancia perimetral.

# Tecnologías Utilizadas

* **Frontend:** React.js
* **Backend:** Node.js / Express
* **Base de Datos:** PostgreSQL
* **Otros:** Python (para scripts de procesamiento o análisis de datos auxiliares)
